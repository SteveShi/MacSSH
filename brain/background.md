# Project background

MacSSH is a modern, fast, and native SSH & SFTP client handcrafted for macOS. It combines GPU-accelerated terminal emulation with an integrated dual-pane SFTP file browser and secure Keychain credential management.

## Goals
- Deliver a native, ultra-responsive SSH terminal powered by Ghostty core.
- Provide a robust SFTP file manager with drag-and-drop support.
- Zero electron / web bloat, built purely in Swift 6.
